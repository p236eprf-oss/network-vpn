# 网络与 VPN 排查工作区

用于处理网络连接与 VPN 使用问题，保存可复用的排查结论、操作说明和诊断脚本。当前已建立文档与版本管理基础，并收录 Clash Verge 分流配置指南；尚无诊断脚本或运行依赖。

远程仓库：[network-vpn](https://github.com/p236eprf-oss/network-vpn) 。

## 如何使用

在此目录发起具体排查任务，尽量提供：

- 系统与版本、VPN 客户端及版本。
- 网络环境，例如家庭 Wi-Fi、公司网络或手机热点。
- 故障表现、错误提示、开始时间和最近改动。
- 受影响的目标与范围，例如全部无法联网、仅域名解析失败或仅 VPN 内资源不可达。
- 希望恢复的状态，以及允许修改的配置范围。

例如：“macOS 上开启 VPN 后浏览器无法访问网页，关闭后恢复正常，请先做只读排查。”

排查优先收集只读证据，再根据原因实施必要修复。敏感配置和原始日志应保留在本地任务临时目录；对外提供信息前先脱敏。
