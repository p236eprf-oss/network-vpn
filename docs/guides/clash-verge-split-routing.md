# Clash Verge：国内直连、海外代理

## 适用场景与结论

在 Clash Verge 开启虚拟网卡（TUN）、使用规则模式，并已选好代理节点的情况下，通过给当前订阅添加国内直连的前置规则，实现国内域名与中国大陆 IP 优先直连，其余流量由原订阅规则和代理兜底处理。

本次操作发生于 2026-11-06，用户完成操作后反馈“可以了”。具体客户端版本未记录；以下步骤以本次截图实际显示的菜单和编辑界面为准。

TUN 负责把系统流量交给 Clash；规则负责决定直连、代理或拦截；节点负责代理连接的出口。仅开启 TUN、选择规则模式和美国节点，不会自动生成国内直连规则。

## 修改前的现象与定位

- 用户希望国内访问直连、海外访问通过已选代理节点。
- “连接”页截图中，ChatGPT、WorkBuddy、Google、VS Code 和腾讯遥测等可见连接均显示 `Match`，链路均经过 `PROXY` 和同一节点，未见 `DIRECT`。
- 后续“编辑规则”截图中，右侧仅显示一条 `MATCH → PROXY`。
- 证据表明，可见连接都进入了代理兜底，没有命中国内直连规则；不能据此断言整台设备的所有流量均走代理，也未据此验证节点出口所在地。

## 实际成功的操作步骤

### 1. 从当前订阅打开规则编辑器

进入“订阅”页面，找到蓝色边框的当前启用订阅卡片，在卡片上右键点击；Mac 触控板可双指点按。选择“编辑规则”。

本次页面下方还显示“全局扩展覆写配置（Merge）”和“全局扩展脚本（Script）”卡片。本次使用的是订阅卡片右键菜单中的“编辑规则”，无需进入这两个全局扩展入口。

### 2. 新增两条前置规则

编辑器左侧有“规则类型”“规则内容”“代理策略”三个输入项，以及“↑ 添加前置规则”“↓ 添加后置规则”按钮；右侧显示现有规则。

保留现有 `MATCH → PROXY`，依次执行：

| 添加顺序 | 规则类型 | 规则内容 | 代理策略 | 填完后的操作 |
|---|---|---|---|---|
| 第一条 | 下拉选择包含 `GEOIP` 的选项 | `CN` | 直接连接（`DIRECT`） | 点击“↑ 添加前置规则” |
| 第二条 | 下拉选择包含 `GEOSITE` 的选项 | `cn` | 直接连接（`DIRECT`） | 点击“↑ 添加前置规则” |

第一条内容为大写 `CN`，第二条为小写 `cn`。规则类型必须切换到对应选项，不使用默认的完整域名匹配类型。每条分别添加一次。

### 3. 检查规则顺序与模式

确认国内直连规则排在 `MATCH` 之前，核心顺序为：

```yaml
rules:
  - GEOSITE,cn,DIRECT
  - GEOIP,CN,DIRECT
  - MATCH,PROXY
```

这段 YAML 用于说明核心结构，无需把整段粘贴到可视化输入框，也不用于覆盖完整订阅文件。其他订阅规则应保留，并结合实际顺序判断效果。

- `GEOSITE,cn,DIRECT`：国内域名集合优先直连。
- `GEOIP,CN,DIRECT`：目标 IP 属于中国大陆时直连。
- `MATCH,PROXY`：前面都未匹配时交给 `PROXY`。

继续保持“虚拟网卡开启＋规则模式”，在 `PROXY` 策略组中保持选择所需代理节点。

## 验收与本次结果

配置生效后，重新打开测试网站，在“连接”页检查新产生的连接，避免拿修改前的旧连接判断效果：

| 检查对象 | 预期结果 |
|---|---|
| 百度等被国内规则覆盖的网站 | 链路显示 `DIRECT` |
| ChatGPT 等应走代理的服务 | 链路显示 `PROXY / 所选节点` |
| 规则顺序 | 国内直连规则位于 `MATCH` 前面 |

本次结果：用户按上述界面操作后反馈“可以了”，确认配置成功。未获得修改后的连接截图，也未由 Agent 读取运行配置或执行连通性检查，因此不记录为逐站点独立验证通过；客户端版本、完整规则列表和节点出口 IP 未核验。

## 容易混淆的点与恢复方法

- “编辑规则”是当前订阅卡片的右键菜单项，页面下方的全局扩展卡片不是本次入口。
- 使用“添加前置规则”。无条件 `MATCH` 后面的规则无法继续匹配到请求。
- `MATCH → PROXY` 需要保留在末尾；将它放到直连规则前面，会使后续直连规则失效。
- 规则模式按配置匹配，不会自动测试网站能否直连后再决定路径。域名与 IP 数据库分类并非绝对准确，个别网站需要按实际连接结果补充例外。
- 本方案保留原订阅规则。如果其中还有其他直连规则，部分海外请求仍可能直连；不能仅凭这两条新增规则保证所有海外流量均走代理。
- 如需撤销本次修改，仅删除本次新增的 `GEOSITE,cn,DIRECT` 和 `GEOIP,CN,DIRECT` 两条前置规则，保留原规则及节点选择，再检查配置加载与连接结果。

本次操作未涉及 DNS、系统路由、TUN 参数或节点凭据的手动修改。原始截图含订阅与节点信息，不复制到项目中。
